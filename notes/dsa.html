1. Two Sum must

Given an array of integers and a target, return the indices of the two numbers that add up to target. Exactly one valid answer; same element cannot be used twice.

Input: nums = [2, 7, 11, 15], target = 9 Output: [0, 1] // nums[0] + nums[1] = 9
Input: nums = [3, 2, 4], target = 6 Output: [1, 2] // 2 + 4 = 6
Input: nums = [3, 3], target = 6 Output: [0, 1]
APPROACH

For each number x, we need target − x to also exist in the array. Instead of searching for the complement every time (O(n)), store every number we've seen in a HashMap as we walk left-to-right.

  1. Walk through the array once.
  2. For each nums[i], compute complement = target − nums[i].
  3. If complement is already in the map → answer is [map.get(complement), i].
  4. Otherwise, put nums[i] → i into the map and continue.
arrayhashmap
Brute Force O(n²) timeO(1) space

Check every pair with two nested loops. Works but quadratic — fine for n ≤ 1000, slow beyond that.

public int[] twoSum(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++)
        for (int j = i + 1; j < nums.length; j++)
            if (nums[i] + nums[j] == target)
                return new int[]{i, j};
    return new int[]{};
}
Optimal — HashMap O(n) timeO(n) space

For each number, check if its complement (target − num) is already in the map. One pass. The classic "trade space for time" pattern.

public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> seen = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (seen.containsKey(complement))
            return new int[]{seen.get(complement), i};
        seen.put(nums[i], i);
    }
    return new int[]{};
}
2. Contains Duplicate

Return true if any value appears at least twice in the array; false if every element is distinct.

Input: [1, 2, 3, 1] Output: true
Input: [1, 2, 3, 4] Output: false
Input: [1, 1, 1, 3, 3, 4, 3, 2, 4, 2] Output: true
APPROACH

The classic "have I seen this before?" pattern. A HashSet lets us answer that in O(1).

  1. Walk through the array.
  2. Try to add each element to a HashSet.
  3. If add() returns false, we've seen this number → return true.
  4. If we finish the loop without a duplicate → return false.
arrayhashset
Brute / Sort O(n log n) timeO(1) space

Sort the array and check adjacent pairs.

public boolean containsDuplicate(int[] nums) {
    Arrays.sort(nums);
    for (int i = 1; i < nums.length; i++)
        if (nums[i] == nums[i - 1]) return true;
    return false;
}
Optimal — HashSet O(n) timeO(n) space

Walk once and try to add to a set; if add() returns false, we've seen it before.

public boolean containsDuplicate(int[] nums) {
    Set<Integer> seen = new HashSet<>();
    for (int n : nums)
        if (!seen.add(n)) return true;
    return false;
}
3. Best Time to Buy and Sell Stock

Given an array where prices[i] is the price of a stock on day i, return the maximum profit from one buy + one sell. You must buy before you sell. Return 0 if no profit is possible.

Input: [7, 1, 5, 3, 6, 4] Output: 5 // buy at 1 (day 2), sell at 6 (day 5)
Input: [7, 6, 4, 3, 1] Output: 0 // prices keep falling — no profit
Input: [2, 4, 1] Output: 2 // buy at 2, sell at 4 (don't wait for 1)
APPROACH

For each day, the best sell price gives price[today] − min(price so far). So we just need to track the minimum price seen so far as we walk left-to-right.

  1. Initialize minPrice = ∞, maxProfit = 0.
  2. For each price, update minPrice = min(minPrice, price).
  3. Then update maxProfit = max(maxProfit, price − minPrice).
  4. One pass, no extra memory.
arraygreedy
Brute Force O(n²) timeO(1) space

Try every pair (buy day, sell day) and track the max difference.

public int maxProfit(int[] p) {
    int max = 0;
    for (int i = 0; i < p.length; i++)
        for (int j = i + 1; j < p.length; j++)
            max = Math.max(max, p[j] - p[i]);
    return max;
}
Optimal — single pass O(n) timeO(1) space

Track the lowest price so far. At each day, profit if sold today = current − minSoFar. Update the max.

public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE, maxProfit = 0;
    for (int p : prices) {
        if (p < minPrice) minPrice = p;
        else maxProfit = Math.max(maxProfit, p - minPrice);
    }
    return maxProfit;
}
4. Product of Array Except Self must

Return an array where output[i] equals the product of every element except nums[i]. Cannot use division (so you can't just compute total product / nums[i]).

Input: [1, 2, 3, 4] Output: [24, 12, 8, 6] // (2·3·4), (1·3·4), (1·2·4), (1·2·3)
Input: [-1, 1, 0, -3, 3] Output: [0, 0, 9, 0, 0] // zeros wipe everything except their own slot
Input: [2, 3, 4, 5] Output: [60, 40, 30, 24]
APPROACH

For index i: answer = (product of everything to its left) × (product of everything to its right). Compute these in two passes.

  1. Pass 1 (left → right): fill ans[i] with the prefix product (product of all elements before i).
  2. Pass 2 (right → left): keep a running right product and multiply ans[i] *= right, then update right *= nums[i].
  3. Total: O(n) time, O(1) extra space (output array doesn't count).
arrayprefix-suffix
Brute Force O(n²) timeO(n) space

For each i, multiply every other element.

public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] ans = new int[n];
    for (int i = 0; i < n; i++) {
        int prod = 1;
        for (int j = 0; j < n; j++)
            if (i != j) prod *= nums[j];
        ans[i] = prod;
    }
    return ans;
}
Optimal — prefix & suffix O(n) timeO(1) extra

For each index, the answer is (product of everything to the left) × (product of everything to the right). Two passes: left to right storing prefix products, then right to left multiplying by running suffix.

public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] ans = new int[n];

    ans[0] = 1;
    for (int i = 1; i < n; i++)
        ans[i] = ans[i - 1] * nums[i - 1];     // prefix

    int right = 1;
    for (int i = n - 1; i >= 0; i--) {
        ans[i] *= right;                       // multiply by suffix
        right *= nums[i];
    }
    return ans;
}
5. Maximum Subarray (Kadane's Algorithm) must

Find the contiguous subarray with the largest sum. Return that sum. Array may contain negative numbers.

Input: [-2, 1, -3, 4, -1, 2, 1, -5, 4] Output: 6 // subarray [4, -1, 2, 1]
Input: [1] Output: 1
Input: [5, 4, -1, 7, 8] Output: 23 // entire array
APPROACH — Kadane's Algorithm

At every index ask one question: "is it better to extend the current subarray, or restart from here?"

  1. Let curr = best subarray sum ending exactly at index i.
  2. Recurrence: curr = max(nums[i], curr + nums[i]) — extend or restart.
  3. Track the overall best: best = max(best, curr).
  4. If curr + nums[i] < nums[i], the previous subarray is dragging us down — drop it.
arrayDPkadane
Brute Force O(n²) timeO(1) space

Try every starting index, extend, track max.

public int maxSubArray(int[] nums) {
    int max = Integer.MIN_VALUE;
    for (int i = 0; i < nums.length; i++) {
        int sum = 0;
        for (int j = i; j < nums.length; j++) {
            sum += nums[j];
            max = Math.max(max, sum);
        }
    }
    return max;
}
Optimal — Kadane O(n) timeO(1) space

At each index decide: extend the previous best, or start fresh from here. Formula: f(i) = max(nums[i], f(i-1) + nums[i]).

public int maxSubArray(int[] nums) {
    int curr = nums[0], best = nums[0];
    for (int i = 1; i < nums.length; i++) {
        curr = Math.max(nums[i], curr + nums[i]);
        best = Math.max(best, curr);
    }
    return best;
}

6. Valid Anagram

Return true if t is an anagram of s — meaning both strings contain the same letters with the same counts, just possibly in a different order.

Input: s = "anagram", t = "nagaram" Output: true
Input: s = "rat", t = "car" Output: false
Input: s = "listen", t = "silent" Output: true
APPROACH

Two strings are anagrams iff their character frequency histograms match. Skip sorting (O(n log n)) and use a counting array.

  1. Quick check: if lengths differ, return false.
  2. Use a 26-int array (lowercase a–z).
  3. Increment for each char in s, decrement for each char in t.
  4. If every bucket is 0 at the end → anagram.
stringfrequency
Sort & Compare O(n log n) timeO(n) space 
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    char[] a = s.toCharArray(), b = t.toCharArray();
    Arrays.sort(a); Arrays.sort(b);
    return Arrays.equals(a, b);
}
Optimal — frequency count O(n) timeO(1) space

Increment for chars in s, decrement for chars in t. If every bucket is zero, it's an anagram. Fixed-size array (26) → O(1) space.

public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] count = new int[26];
    for (int i = 0; i < s.length(); i++) {
        count[s.charAt(i) - 'a']++;
        count[t.charAt(i) - 'a']--;
    }
    for (int c : count) if (c != 0) return false;
    return true;
}
7. Longest Substring Without Repeating Characters must

Find the length of the longest substring (contiguous) of s that contains all unique characters (no repeats).

Input: "abcabcbb" Output: 3 // "abc"
Input: "bbbbb" Output: 1 // "b"
Input: "pwwkew" Output: 3 // "wke" (not "pwke" — that's a subsequence)
APPROACH — Sliding Window

Maintain a window [left, right] that always contains unique characters. Expand right; if a duplicate appears, jump left past its last occurrence.

  1. Use a HashMap<char, lastIndex>.
  2. Move right through the string.
  3. If s[right] was seen and its last index ≥ left: move left = lastIdx + 1.
  4. Update map[s[right]] = right and maxLen = max(maxLen, right − left + 1).
stringsliding-window
Brute Force O(n³) timeO(n) space

Generate every substring, check uniqueness with a set.

public int lengthOfLongestSubstring(String s) {
    int max = 0;
    for (int i = 0; i < s.length(); i++)
        for (int j = i + 1; j <= s.length(); j++)
            if (allUnique(s, i, j)) max = Math.max(max, j - i);
    return max;
}
private boolean allUnique(String s, int i, int j) {
    Set<Character> set = new HashSet<>();
    for (int k = i; k < j; k++)
        if (!set.add(s.charAt(k))) return false;
    return true;
}
Optimal — sliding window O(n) timeO(k) space

Expand the right edge; if we hit a duplicate, jump the left edge past its last position. Map stores the latest index of each char.

public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> lastIdx = new HashMap<>();
    int max = 0, left = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (lastIdx.containsKey(c) && lastIdx.get(c) >= left)
            left = lastIdx.get(c) + 1;
        lastIdx.put(c, right);
        max = Math.max(max, right - left + 1);
    }
    return max;
}
8. Group Anagrams

Given an array of strings, group all anagrams together. Each group goes into its own list.

Input: ["eat","tea","tan","ate","nat","bat"] Output: [["eat","tea","ate"], ["tan","nat"], ["bat"]]
Input: [""] Output: [[""]]
Input: ["a"] Output: [["a"]]
APPROACH

All anagrams share the same canonical key. Build a key per word, then group by key in a HashMap.

  1. For each word, build a character-count "fingerprint" (a 26-int array).
  2. Use its string representation as a map key.
  3. Add the original word to map[key]'s list.
  4. Return all the lists.

Alternative key: sort the word's characters. Simpler to write but slower (O(k log k) per word).

stringhashmap
Sort key — readable O(n·k log k)O(n·k)

Sort each word's characters to form a canonical key, then group.

public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] c = s.toCharArray();
        Arrays.sort(c);
        map.computeIfAbsent(new String(c), k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
Optimal — count key O(n·k) timeO(n·k)

Build a 26-int key from each word's char frequencies — no sorting. k = avg word length.

public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        int[] count = new int[26];
        for (char ch : s.toCharArray()) count[ch - 'a']++;
        String key = Arrays.toString(count);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
9. Valid Parentheses must

Given a string of just (), [], {} characters, return true if every open bracket has a matching close and they're properly nested.

Input: "([{}])" Output: true
Input: "([)]" Output: false // brackets cross — not nested
Input: "{[]}" Output: true
APPROACH — Stack matching

Every close bracket must match the most recent unmatched open bracket — that's exactly what a stack tracks.

  1. For each character:
  2. If it's an opener ((, [, {) → push onto stack.
  3. If it's a closer → stack must not be empty, and top must be the matching opener; pop it. Otherwise false.
  4. At the end, the stack must be empty (all opens were closed).
stringstack
Optimal — Stack O(n) timeO(n) space

Push opens, on close pop and check it matches. Empty stack at the end → valid.

public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') stack.push(c);
        else {
            if (stack.isEmpty()) return false;
            char top = stack.pop();
            if (c == ')' && top != '(') return false;
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
        }
    }
    return stack.isEmpty();
}
10. Longest Palindromic Substring

Return the longest contiguous substring of s that reads the same forward and backward.

Input: "babad" Output: "bab" or "aba" // either is valid
Input: "cbbd" Output: "bb"
Input: "racecar" Output: "racecar"
APPROACH — Expand Around Center

Every palindrome has a center — one character (odd length) or a gap between two characters (even length). There are 2n − 1 possible centers.

  1. For each index i:
  2. Expand outward from (i, i) — odd-length center.
  3. Expand outward from (i, i+1) — even-length center.
  4. Keep growing while s[left] == s[right].
  5. Track the longest palindrome found.
stringtwo-pointer
Brute Force O(n³) timeO(1) space

Check every substring for palindrome.

// for each (i, j) check s.substring(i,j) is palindrome,
// track the longest. O(n²) substrings × O(n) palindrome check.
Optimal — Expand Around Center O(n²) timeO(1) space

Every palindrome has a center (one char for odd, gap for even). For each of the 2n−1 centers, expand outward while characters match.

public String longestPalindrome(String s) {
    if (s.isEmpty()) return "";
    int start = 0, end = 0;
    for (int i = 0; i < s.length(); i++) {
        int len1 = expand(s, i, i);     // odd centre
        int len2 = expand(s, i, i + 1); // even centre
        int len = Math.max(len1, len2);
        if (len > end - start) {
            start = i - (len - 1) / 2;
            end   = i + len / 2;
        }
    }
    return s.substring(start, end + 1);
}
private int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return r - l - 1;
}

11. Maximum Sum Subarray of Size K

Find the maximum sum of any contiguous subarray of exactly size k.

Input: nums = [2, 1, 5, 1, 3, 2], k = 3 Output: 9 // [5, 1, 3]
Input: nums = [1, 4, 2, 10, 23, 3, 1, 0, 20], k = 4 Output: 39 // [4, 2, 10, 23]
Input: nums = [100, 200, 300, 400], k = 2 Output: 700 // [300, 400]
APPROACH — Fixed Sliding Window

Classic "don't recompute, just slide" trick. Instead of summing k elements every time (O(n·k)), just adjust the running sum as the window moves.

  1. Compute the sum of the first k elements → initial window sum.
  2. Slide right by 1 each step:
  3. sum += nums[right] − nums[right − k] — add the entering element, remove the leaving one.
  4. Track max(sum) across all slides.
arraysliding-window
Brute Force O(n·k) timeO(1) space 
public int maxSum(int[] nums, int k) {
    int max = Integer.MIN_VALUE;
    for (int i = 0; i + k <= nums.length; i++) {
        int sum = 0;
        for (int j = i; j < i + k; j++) sum += nums[j];
        max = Math.max(max, sum);
    }
    return max;
}
Optimal — fixed window O(n) timeO(1) space

Compute the first window's sum, then slide: subtract the element leaving, add the element entering.

public int maxSum(int[] nums, int k) {
    int sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i];
    int max = sum;
    for (int i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];
        max = Math.max(max, sum);
    }
    return max;
}
12. Minimum Window Substring hot

Given strings s and t, return the smallest substring of s that contains every character of t (counting duplicates). Return "" if no such window exists.

Input: s = "ADOBECODEBANC", t = "ABC" Output: "BANC"
Input: s = "a", t = "a" Output: "a"
Input: s = "a", t = "aa" Output: "" // not enough a's
APPROACH — Variable Sliding Window (Expand & Shrink)

Move two pointers left and right over s. Expand right until the window contains all of t; then shrink left as long as it still does. Track the smallest valid window.

  1. Build a frequency map need for t.
  2. Expand right: as you see required characters, count how many requirements are "satisfied".
  3. When all requirements are met → try shrinking left while the window stays valid; record window size.
  4. Continue expanding right; repeat.
stringsliding-window
Optimal — expand-shrink window O(n) timeO(k) space

Two pointers. Expand right until the window contains all of t, then shrink left as long as it still does. Track the smallest valid window.

public String minWindow(String s, String t) {
    if (t.isEmpty() || s.length() < t.length()) return "";
    Map<Character, Integer> need = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);

    int required = need.size(), formed = 0;
    Map<Character, Integer> window = new HashMap<>();
    int left = 0, bestLen = Integer.MAX_VALUE, bestL = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        window.merge(c, 1, Integer::sum);
        if (need.containsKey(c) && window.get(c).intValue() == need.get(c).intValue())
            formed++;

        while (formed == required) {
            if (right - left + 1 < bestLen) {
                bestLen = right - left + 1;
                bestL = left;
            }
            char lc = s.charAt(left);
            window.merge(lc, -1, Integer::sum);
            if (need.containsKey(lc) && window.get(lc) < need.get(lc))
                formed--;
            left++;
        }
    }
    return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestL, bestL + bestLen);
}

13. Reverse Linked List must

Reverse a singly linked list — flip every next pointer so the list goes the other way. Return the new head.

Input: 1 → 2 → 3 → 4 → 5 Output: 5 → 4 → 3 → 2 → 1
Input: 1 → 2 Output: 2 → 1
Input: [] (empty list) Output: []
APPROACH — Three Pointers (iterative)

Walk through the list and flip each next pointer in place. The key is to remember the next node before overwriting it.

  1. Use 3 references: prev = null, curr = head, next.
  2. Save next = curr.next before overwriting.
  3. Flip the pointer: curr.next = prev.
  4. Advance: prev = curr, curr = next.
  5. When curr == null, prev is the new head.
linked-listtwo-pointer
Optimal — iterative O(n) timeO(1) space

Walk the list flipping each next pointer. Three references: prev, curr, next.

public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
Alternative — recursive O(n) timeO(n) stack 
public ListNode reverseList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode rest = reverseList(head.next);
    head.next.next = head;
    head.next = null;
    return rest;
}
14. Detect Cycle in Linked List must

Return true if the linked list contains a cycle — i.e. some next pointer goes back to an earlier node, creating an infinite loop.

Input: 3 → 2 → 0 → -4 → (back to 2) Output: true
Input: 1 → 2 → null Output: false
Input: 1 → (back to 1) Output: true
APPROACH — Floyd's Tortoise & Hare

Two pointers moving at different speeds. If there's a cycle, the fast one will eventually lap the slow one — they must meet. If there's no cycle, fast hits null.

  1. Start slow and fast at head.
  2. Each iteration: slow = slow.next, fast = fast.next.next.
  3. If fast (or fast.next) becomes null → no cycle.
  4. If slow == fast → cycle detected.
  5. Beats the HashSet approach in space (O(1) vs O(n)).
linked-listtwo-pointerfloyd
HashSet O(n) timeO(n) space 
public boolean hasCycle(ListNode head) {
    Set<ListNode> seen = new HashSet<>();
    while (head != null) {
        if (!seen.add(head)) return true;
        head = head.next;
    }
    return false;
}
Optimal — Floyd's Tortoise & Hare O(n) timeO(1) space

Slow pointer moves 1 step; fast pointer moves 2. If there's a cycle, fast eventually laps slow and they meet. Otherwise fast hits null.

public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}
15. Merge Two Sorted Linked Lists

Given two sorted linked lists, merge them into a single sorted list by splicing nodes (no new allocations). Return the head.

Input: l1 = 1→2→4, l2 = 1→3→4 Output: 1→1→2→3→4→4
Input: l1 = [], l2 = [] Output: []
Input: l1 = [], l2 = 0 Output: 0
APPROACH — Dummy Head + Two Pointers

Use a dummy node to avoid awkward "is this the first node?" edge cases. Walk both lists simultaneously and attach the smaller head each step.

  1. Create dummy node and pointer tail = dummy.
  2. While both lists have nodes: attach the smaller node to tail.next, advance that list's pointer.
  3. Move tail = tail.next.
  4. When one list runs out, attach the other entirely (it's already sorted).
  5. Return dummy.next.
linked-listtwo-pointer
Optimal — dummy head + two pointers O(n + m) timeO(1) space

Use a dummy node so we don't special-case the head. Walk both lists, append the smaller one each step.

public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
        else                  { tail.next = l2; l2 = l2.next; }
        tail = tail.next;
    }

class LRUCache {
    class Node { int key, val; Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }
    private final Map<Integer, Node> map = new HashMap<>();
    private final int capacity;
    private final Node head = new Node(0, 0), tail = new Node(0, 0);

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail; tail.prev = head;
    }

    public int get(int key) {
        Node n = map.get(key);
        if (n == null) return -1;
        remove(n); addToHead(n);
        return n.val;
    }

    public void put(int key, int value) {
        Node n = map.get(key);
        if (n != null) { n.val = value; remove(n); addToHead(n); return; }
        if (map.size() == capacity) {
            map.remove(tail.prev.key);
            remove(tail.prev);
        }
        Node fresh = new Node(key, value);
        map.put(key, fresh);
        addToHead(fresh);
    }

    private void addToHead(Node n) {
        n.next = head.next; n.prev = head;
        head.next.prev = n; head.next = n;
    }
    private void remove(Node n) {
        n.prev.next = n.next; n.next.prev = n.prev;
    }
}

        }
