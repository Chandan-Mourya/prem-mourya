View logs with tail -f /path/app.log, less, or centralized Splunk/ELK search.

How do you search error in logs?

Search errors with grep -i error app.log, grep -E 'ERROR|EXCEPTION|ORA-', and context lines grep -B3 -A10.

Practice

Start from first error after deployment time; follow stack trace root cause.

Splunk: <code>index=prod sourcetype=app ERROR | head 50</code>.

How do you check memory usage?

OS memory: free -h; Java heap: jstat -gcutil <pid> or VisualVM.

Interpretation

High swap usage indicates memory pressure; frequent Full GC in jstat → heap tuning or leak.

How do you check CPU usage?

CPU: top, htop, or top -H -p <java-pid> for per-thread CPU in Java troubleshooting.

Next step

If Java process hot, take jstack and match high-CPU thread nid.

How do you kill a process?

Stop process with kill <pid> (SIGTERM) or kill -9 <pid> (force — last resort).

Safety

Prefer graceful shutdown: WebLogic Admin Console stop; <code>kill -15</code> before -9.

Document PID and reason in change ticket for production.

How do you check open ports?

Check listening ports: netstat -tlnp or ss -tlnp; test connectivity telnet host 1521 or nc -zv host 8080.

Banking

Oracle 1521, WebLogic 7001/7002, MQ 1414 — firewall rules must allow only required peers.

How do you schedule cron job?

Schedule with crontab -e — format: minute hour day month weekday command.

Example
0 2 * * * /opt/scripts/archive_logs.sh — daily at 02:00.

Use absolute paths; redirect output to log; avoid overlapping long jobs.

How do you write shell script?

Shell scripts start with #!/bin/bash, use variables, conditionals, loops, and exit codes for automation.

Example
#!/bin/bash set -euo pipefail LOG=/var/log/backup.log echo "$(date) start" >> "$LOG" set -e exits on error — safer for ops scripts.
How do you pass arguments to shell script?

Access arguments as $1, $2, $@ (all), $# (count); script invoked as ./script.sh arg1 arg2.

Example
ENV=$1; DATE=$2; echo "Running for $ENV on $DATE"
How do you check exit status?

Exit status of last command: echo $? — 0 means success, non-zero failure.

Scripting
if ! grep -q ERROR app.log; then echo OK; else exit 1; fi

Use in CI/cron to alert on failure.

How do you find files modified today?

Find today's files: find /path -type f -mtime 0 or find . -newermt '2024-01-15'.

Use

Locate fresh dumps, logs, or deployments during incident triage.
